# Pydantic AI Image Analysis Project

This project uses Pydantic AI with OpenAI GPT-4o for image analysis and processing.

## Key Technologies
- Pydantic AI for agent-based AI interactions
- OpenAI GPT-4o for multimodal capabilities (text + images)
- Python for core implementation

## Code Style Guidelines
- Use type hints for all function parameters and return values
- Follow Pydantic AI patterns for agent creation and message handling
- Use ImageUrl for web-based images and BinaryContent for local files
- Implement proper error handling for API calls and file operations
- Keep functions focused and modular

## Important Notes
- Always check model capabilities before using image input features
- Use environment variables for API keys and sensitive configuration
- Handle both URL-based and local file-based image inputs
- Implement proper logging for debugging and monitoring
