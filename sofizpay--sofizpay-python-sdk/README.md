> Tome by [SofizPay](https://github.com/SofizPay/sofizpay-python-sdk), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

The official SofizPay Python SDK repository provides a clean, native Python library designed to interface seamlessly with the SofizPay API. It allows developers to integrate SofizPay wallet payment, local Algerian bank-card deposits (CIB / Edahabiya), and various utility recharges directly into Python applications.
