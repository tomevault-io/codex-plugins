
# Git commit messages

When creating or suggesting git commit messages for this repository, **do not** append or include any of the following:

- `Co-authored-by: Cursor <cursoragent@cursor.com>`
- Any other `Co-authored-by:` line for Cursor or the agent

Write only the conventional commit subject/body the user or workflow needs, without co-author trailers.
