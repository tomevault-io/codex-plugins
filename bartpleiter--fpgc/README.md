# FPGC

> Source: [bartpleiter/FPGC](https://github.com/bartpleiter/FPGC). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

My huge FPGA hobby project where I learn in detail how computers work by designing my own from scratch at FPGA logic level, and building upon it to create a fully functional physical computer that can compile and run its own software on an OS, without using existing architectures.
