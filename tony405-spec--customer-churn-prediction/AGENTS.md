# Copilot instructions for customer-churn-prediction

## Build, test, run
- Install deps: `pip install -r requirements.txt`
- Run full tests: `pytest`
- Run a single test: `pytest tests/test_api.py::test_health_check`
- Build Docker image (used in CI): `docker build -t ml-churn-predictor:latest .`
- Run API locally (requires artifacts present): `uvicorn api.app:app --host 0.0.0.0 --port 8000`

## High-level architecture
- The ML pipeline is a sequence of CLI scripts in `src\` that read and write files in `artifacts\` (data splits, encoders, scaler, features, models, metrics) and `reports\` (plots, drift report). These steps are orchestrated in GitHub Actions workflows (`pipeline.yml`, `retrain.yml`, `api-test.yml`).
- Data is generated by `scripts\generate_data.py` into `data\fictitious_company_data.xlsx`, then `src\ingest.py` creates `artifacts\raw_data.pkl`, `src\validate.py` performs schema and range checks and writes `artifacts\validation_report.json`, `src\preprocess.py` writes train/test splits and encoders, and `src\feature_engineering.py` adds derived features, scales, and saves `feature_names.pkl` and `fe_params.pkl`.
- Model training and evaluation run via `src\train.py` and `src\evaluate.py` for `logistic_regression`, `random_forest`, and `xgboost`; `src\select_model.py` chooses the best model (F1 then ROC-AUC) and `src\save_model.py` copies the winner to `artifacts\model.pkl` and writes reports.
- The FastAPI service in `api\app.py` loads model and preprocessing artifacts from `artifacts\` at startup and exposes `/health` and `/predict`. Drift checks used in workflows run `scripts\drift_detection.py` and write `reports\drift_report.json`.

## Key conventions and gotchas
- Artifact paths and filenames are hard-coded across scripts, API, and tests. Keep `artifacts\*.pkl` and `artifacts\metrics.json` stable unless you update every consumer.
- Feature engineering must stay in sync between `src\feature_engineering.py` and `api\app.py` (derived features plus `fe_params` and `feature_names` ordering).
- Tests use `conftest.py` to preload artifacts because httpx ASGI transport does not trigger FastAPI lifespan. Local test runs assume the artifacts already exist.
- CLI scripts expect arguments and exit non-zero on validation or training failures (used by CI workflows). Maintain this behavior when modifying pipeline steps.
