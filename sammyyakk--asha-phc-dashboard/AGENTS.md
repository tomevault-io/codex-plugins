## Project Overview

PHC Staff Dashboard - A comprehensive desktop dashboard for PHC doctors/nurses/supervisors built with React, Next.js 14+, TypeScript, Tailwind CSS, and Framer Motion.

## How to Run

1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Open browser to: http://localhost:3000
4. Login and select a role to access dashboard

## Technology Stack

- Next.js 14+ with App Router
- TypeScript for type safety
- Tailwind CSS for styling
- Framer Motion for animations
- Recharts for data visualization
- Lucide React for icons

## Project Structure

- `/src/app` - Next.js pages and routing
- `/src/components` - Reusable React components
- `/src/types` - TypeScript type definitions
- All pages use the DashboardLayout component for consistent navigation
