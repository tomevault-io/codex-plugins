# Nice Beard - Luxury Barbershop Website

## Project Overview
Modern React + TypeScript + Tailwind CSS + Vite project for a luxury barbershop with Arabic/English i18n support, Framer Motion animations, and professional component architecture.

## Key Technologies
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Internationalization**: i18next
- **HTTP Client**: Axios

## Project Structure
```
src/
├── components/       # Reusable React components
├── pages/           # Page components
├── hooks/           # Custom React hooks
├── services/        # API and utility services
├── types/           # TypeScript interfaces
├── i18n/            # Internationalization config
├── styles/          # Global styles
└── App.tsx          # Main app component
```

## Development Commands
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Features
- Bilingual support (Arabic/English with RTL support)
- Responsive design for all devices
- Smooth animations and transitions
- Live opening status indicator
- Dynamic navigation
- SEO optimized
