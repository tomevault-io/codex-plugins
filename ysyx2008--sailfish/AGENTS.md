
# Spec 驱动开发

模块目录下的 `SPEC.md`（或 `*_SPEC.md`）描述模块契约（职责、API、依赖、约束），是理解模块的首要入口。

- **改动前**：先检查目录下有无 SPEC.md，有则先读
- **改动后**：若新增/删除公开方法、改变职责或约束，同步更新 SPEC.md
- **新增模块**：创建 SPEC.md（50-150 行，指向类型定义而非复制）
