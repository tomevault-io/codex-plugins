# ProgramAT-opensource

> Source: [program-at/ProgramAT-opensource](https://github.com/program-at/ProgramAT-opensource) — distributed by [TomeVault](https://tomevault.io)

ProgramAT is a mobile app that enables users to create, run, and iteratively refine bespoke camera-based assistive technologies using natural-language input. It connects to an agentic coding backend and cloud infrastructure to translate user prompts into functional tools that can be immediately tested and adapted in real-world contexts.
