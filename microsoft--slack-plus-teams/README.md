# slack-plus-teams

> Tome by [microsoft](https://github.com/microsoft/slack-plus-teams), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

slack-plus-teams is a lightweight compatibility layer that enables developers to run the same bot logic on both Slack and Microsoft Teams. Build once, deploy to both platforms, and bridge the gap between Slack and Teams APIs with minimal changes.
