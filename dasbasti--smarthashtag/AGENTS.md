# SmartHashtag

## Test builds for reporters

Reporters can install a test commit from Home Assistant without downloading anything:
Developer tools → Actions → `update.install`, target the "Smart #1/#3 Integration" update entity,
set `version` to the short commit hash. Point them at that, not a manual zip install.
