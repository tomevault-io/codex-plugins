# TomeVault Codex Plugins

AI instruction files in `AGENTS.md` format, packaged as OpenAI Codex agent plugins. Each is graded against the public Tome Standard and kept in sync across every major AI platform by [TomeVault](https://tomevault.io).

## Install

Browse the per-plugin directories and copy a plugin's `AGENTS.md` into your project root, or follow the per-plugin README for setup steps.

## Browse

Search, filter, and discover instruction files across every platform at [tomevault.io](https://tomevault.io).

> Every package links its original creator. Graded against the public [Tome Standard](https://tomevault.io/standards) and kept in sync across platforms by [TomeVault](https://tomevault.io).
