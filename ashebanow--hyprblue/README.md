# hyprblue

> Tome by [ashebanow](https://github.com/ashebanow/hyprblue) — distributed by [TomeVault](https://tomevault.io)

A maximalist custom build of bazzite and bluefin that adds support for hyprland, niri, and many of the apps they use. If you want one that only includes the base set of apps your Window Manager configuration needs, then fork it and edit the build_files/build.sh file's HYPR_DEPS variable to remove the stuff you don't want.

## Codex Config

The `AGENTS.md` file in this directory is the project config converted for Codex.
Original source: `copilot-instructions.md` in [ashebanow/hyprblue](https://github.com/ashebanow/hyprblue).
