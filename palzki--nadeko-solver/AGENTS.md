# Hangman Solve workspace instructions

- This is a Vite + React + TypeScript app.
- Keep solver behavior in `src/solver.ts` and the bundled corpus in `src/words.ts`.
- The app is local-only and must not add Discord credentials, message uploads, or a backend unless explicitly requested.
- Run `npm run build` after changes that touch TypeScript or the Vite configuration.
