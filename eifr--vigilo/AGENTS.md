# Package Manager Rules
- ALWAYS use `bun` for all package management and script execution.
- To install dependencies, use `bun install` or `bun add <package>`.
- To run scripts, use `bun run <script>` or `bun <script>`.
- STRICTLY FORBIDDEN: Do not use `npm`, `yarn`, or `pnpm` under any circumstances.
