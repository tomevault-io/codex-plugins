# Project Overview

This is a new Flutter project named `perfil`. It's a starting point for a Flutter application and includes the basic setup for a Material Design app. The main language is Dart.

# Building and Running

*   **Run the app:** `flutter run`
*   **Run tests:** `flutter test`

# Development Conventions

*   The project follows the standard Flutter project structure.
*   It uses `flutter_lints` for code analysis, which encourages good coding practices. The lint rules are defined in `analysis_options.yaml`.
*   The default test suite is a widget test that verifies the functionality of the counter in the default app.
