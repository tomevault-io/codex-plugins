This project is an attendance management system with a modern Apple-inspired GUI using Tkinter + CustomTkinter. Features include student/class management, attendance marking, reporting, WhatsApp/email communication, data export, backup/restore, error handling, settings, and help/documentation. Use Python 3.8+, SQLite, pandas, openpyxl, pywhatkit, reportlab, .env, unittest, Markdown. Target Windows, optionally macOS. Prepare for packaging with PyInstaller.
