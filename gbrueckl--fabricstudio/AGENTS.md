# General rules for all agents

## ➡️ Response Prefix Requirement

**Always prefix your answers with ➡️** – This is a non-negotiable requirement. Every response must begin with the arrow emoji to maintain consistency and clarity with the development team. This also makses it easy to spot context rot in long conversations.
