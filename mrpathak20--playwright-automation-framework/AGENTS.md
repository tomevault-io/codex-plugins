# Playwright Framework Instructions

This is a production-ready Playwright automation framework.

Always:

- Use JavaScript
- Follow Page Object Model
- Reuse existing utilities
- Never duplicate code
- Use Excel Utility for test data
- Use Report Utility for reporting
- Use Screenshot Utility
- Keep methods reusable
- Use async/await
- Follow existing folder structure

Never:

- Hardcode URLs
- Hardcode credentials
- Create duplicate utilities
- Ignore framework architecture
