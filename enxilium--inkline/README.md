# inkline

> Tome by [enxilium](https://github.com/enxilium/inkline) — distributed by [TomeVault](https://tomevault.io)

Inkline is a dedicated document editor for creative writers. Unlike generic apps like Google Docs or Microsoft Word, we offer dedicated interfaces to keep track of characters, organizations, or locations within your story, and methods to connect them like never before. Think of us like Campfire mixed with Scrivener — but 100% free and open-source.
