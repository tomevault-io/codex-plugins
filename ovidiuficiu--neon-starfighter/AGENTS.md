# Workspace Instructions

- This repository is a Vite vanilla TypeScript canvas game named NEON STARFIGHTER.
- Keep gameplay, input handling, rendering, and game state in `src/main.ts`.
- Keep the responsive visual system and layout in `src/style.css`.
- Preserve keyboard, pointer/touch, pause, audio, power-up, wave, and high-score behavior when changing the game.
- Use `npm run build` as the required compile check after code changes.
- Use the included `Start STARFALL VECTOR` VS Code task for the local development server.
- No additional VS Code extensions are required for this project.
