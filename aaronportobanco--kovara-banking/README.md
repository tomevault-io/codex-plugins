# kovara-banking

> Source: [aaronportobanco/kovara-banking](https://github.com/aaronportobanco/kovara-banking) — distributed by [TomeVault](https://tomevault.io)

Kovara Banking es una aplicación web de banca en línea desarrollada con Next.js y TypeScript. Permite a los usuarios gestionar cuentas bancarias, visualizar transacciones y realizar transferencias, integrando servicios como Appwrite, Plaid y Dwolla (en modo Sandbox).
