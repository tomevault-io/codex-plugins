# Testing Rules

- Contracts: unit tests for deposit, withdraw, trade, and revert cases.
- Contracts: tests for allowlists and unauthorized access.
- Backend: unit tests for strategy logic and signal evaluation.
- Backend: integration tests for REST endpoints with mocked DEX APIs.
- Frontend: component tests for wallet connect and forms.
- Frontend: end-to-end tests for the main user flow.
- Always propose unit tests for new features when applicable.
- Add regression tests for every fixed bug.
