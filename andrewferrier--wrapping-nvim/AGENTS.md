# Contributing to wrapping.nvim

- Always use [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/) in your pull requests.

- Only add comments when they provide useful insight not obvious from the code itself. Let the code explain itself whenever possible.

- Please implement and update unit tests where appropriate.
