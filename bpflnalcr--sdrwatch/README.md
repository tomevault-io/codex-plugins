# SDRwatch

> Source: [BPFLNALCR/SDRwatch](https://github.com/BPFLNALCR/SDRwatch) — distributed by [TomeVault](https://tomevault.io)

SDR-Watch is a tool for wideband spectrum monitoring. It baselines the RF environment, detects and categorizes signals, and maps them to official frequency allocations. It can run continuously to track trends, highlight anomalies, and alert you to new activity through a simple web dashboard.
