### Creating a new component

To create a new component, add a new file to the `src/components` directory. For example, to create a `Header` component:

**File:** `src/components/Header.tsx`
```tsx
import React from ''';

const Header = () => {
  return (
    <header>
      <h1>My App</h1>
    </header>
  );
};

export default Header;
```
