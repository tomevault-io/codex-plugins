# Message-Center-Agent

> Tome by [mjfusa](https://github.com/mjfusa/Message-Center-Agent) — distributed by [TomeVault](https://tomevault.io)

Message Center Agent is a Copilot Declarative Agent that queries Microsoft message center messages and the Microsoft 365 Roadmap with natural language. It leverages the Microsoft Graph API and M365 Roadmap API via OData. Authentication is handled using OAuth2.0 and the Teams Developer Portal.
