## Project Overview
EventGate is a full-stack Next.js 14 event registration system with:
- TypeScript for type safety
- Prisma with SQLite for database
- NextAuth for authentication
- Tailwind CSS with custom orange theme
- React Hot Toast for notifications
- Comprehensive admin dashboard
- Responsive design

## Development Commands
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run db:push` - Update database schema
- `npm run db:generate` - Generate Prisma client
- `npm run db:studio` - Open Prisma Studio

## Project Structure
Complete Next.js 14 App Router structure with API routes, components, and proper TypeScript configuration.

The development server is running at http://localhost:3000
